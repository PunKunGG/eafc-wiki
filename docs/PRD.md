# FC26 Playbook — Product Requirements

สถานะ: ขอบเขต V1 จากการออกแบบที่ตกลงในแชต โครงเริ่มต้นยังไม่ได้ทำฟีเจอร์ครบ

## เป้าหมาย

คู่มือปุ่ม EA SPORTS FC 26 ภาษาไทยสำหรับผู้ใช้จอย PlayStation และ Xbox
ค้นหาคำสั่งได้รวดเร็วระหว่างเล่น พร้อมคำอธิบายเมื่ออยากเรียนรู้เพิ่มเติม

## ขอบเขต V1

| Requirement | เกณฑ์ตรวจรับเมื่อพัฒนาฟีเจอร์ |
| --- | --- |
| หมวดการยิง การส่ง ท่าดีใจ | เลือกหมวดแล้วแสดงเฉพาะรายการที่ตรงกัน |
| ค้นหาภาษาไทยและอังกฤษ | ค้นหาชื่อท่าโดยไม่สนตัวพิมพ์ใหญ่เล็ก และใช้ร่วมกับหมวดได้ |
| PlayStation / Xbox | สลับจอยแล้วเปลี่ยนคำสั่ง โดยคงผลค้นหาและท่าที่เปิดอยู่ |
| ชุดควบคุม Classic | ระบุชุดควบคุมเสมอ ไม่แสดงว่าใช้กับชุดอื่นได้โดยไม่มีข้อมูล |
| รายละเอียด | แสดงปุ่ม ลำดับกด กดค้าง/พร้อมกัน เงื่อนไข และแหล่งข้อมูล |
| รายการโปรด | เพิ่ม/ลบและคงไว้หลัง reload ใน browser เดิม; ถ้าบันทึกไม่ได้ยังอ่านคู่มือได้ |
| Responsive / accessibility | ใช้ได้ที่ 320px ขึ้นไป รองรับคีย์บอร์ด focus ชัดเจน ไม่พึ่งสีอย่างเดียว |
| ความถูกต้องของเนื้อหา | แสดงเฉพาะท่าที่ตรวจแล้ว พร้อมแหล่งข้อมูลและวันที่ตรวจ |

## หน้าหลัก

- `/`: คลังท่า โดยเริ่มจากรูปแบบชีตระหว่างเล่นที่ผู้ใช้เลือก
- `/moves/[slug]`: รายละเอียดที่เปิดผ่านลิงก์ตรงได้ (แผน V1 ยังไม่สร้าง route)
- `/favorites`: รายการโปรดในเครื่อง (แผน V1 ยังไม่สร้าง route)

ชื่อ FC26 Playbook เป็น working title เปลี่ยนชื่อได้โดยไม่กระทบ domain model
เว็บเป็น fan-made guide และไม่ใช้ข้อมูลสาธิตใน mockup เป็นหลักฐานยืนยันคำสั่ง

## แยกออกจาก V1

บัญชีสมาชิก, การ sync ข้ามเครื่อง, admin/CMS, ฐานข้อมูล, community, keyboard mappings,
Alternate/custom bindings, การจัดอันดับนักเตะ, ข้อมูลตลาด, AI และระบบชำระเงิน

ข้อเสนอในอนาคตที่ยังไม่อนุมัติ: คลิปสาธิต ภาพอนาล็อก หมวดเลี้ยงบอล/เกมรับ และชุดฝึก

## ขอบเขตงาน bootstrap รอบนี้

สร้างเอกสาร โครง Next.js theme tokens หน้าแรกแบบ empty state และ data contract
โดยยังไม่พัฒนาค้นหา favorites หรือเผยแพร่เว็บ เกณฑ์ผ่านคือ install, lint, typecheck,
production build และตรวจหน้าแรก/404 ได้ในเครื่อง
