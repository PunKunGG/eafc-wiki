# Midnight Arena

ธีมจากตัวอย่างที่ผู้ใช้เลือก: กรมท่าเข้ม น้ำเงินเทา และฟ้าไซแอน
มุมมองหลักเป็นชีตระหว่างเล่น ปุ่มคำสั่งต้องเห็นก่อนรายละเอียดรอง

| Token | ค่า | บทบาท |
| --- | --- | --- |
| background | `#0B1220` | พื้นหน้า |
| surface | `#162235` | header และ cards |
| foreground | `#EDF2F7` | ข้อความหลัก |
| muted | `#ACBDD1` | คำอธิบายรอง |
| border | `#3D506C` | เส้นแบ่ง |
| accent | `#45D6E8` | selected controls, favorite, focus |
| accent-foreground | `#0B1220` | ข้อความบนปุ่มสี accent |
| accent-subtle | `#193747` | พื้นส่วนที่เลือก |

กำหนด tokens ที่ `src/app/globals.css` ผ่าน Tailwind `@theme` ไม่ทำสีคู่แยกในแต่ละ component
ใช้ system font ที่อ่านไทยได้ (`Tahoma`, `Leelawadee UI`, system-ui) เพื่อให้ build ไม่ต้องโหลด font ภายนอก
หากต้องใช้ webfont ภายหลังให้เลือกไฟล์ที่มีสิทธิ์ใช้และ self-host

## Layout และการใช้งาน

- เนื้อหากว้างไม่เกิน 1120px; ช่องว่างขอบหน้า 16px บนมือถือ เพิ่มเป็น 24–32px บนจอใหญ่
- Header: ชื่อเว็บ ตามด้วยตัวเลือกจอยเมื่อพัฒนาส่วน interactive
- ค้นหา → หมวด → รายการท่า → รายละเอียด ไม่มี hero ใหญ่ขวางคู่มือ
- มือถือจัดหนึ่งคอลัมน์ ห้าม scroll ทั้งหน้าในแนวนอน
- ปุ่มสัมผัสอย่างน้อย 44px, มี visible focus, ใช้ native controls และ accessible labels
- ไม่อธิบายคำสั่งด้วยสีอย่างเดียว ปุ่มจอยต้องมีสัญลักษณ์/ตัวอักษรและชื่อที่อ่านได้
- `+` หมายถึงพร้อมกัน; ลำดับ step ใช้ลูกศร/รายการเลข กดค้างต้องมีคำว่า “กดค้าง”
- empty state ต้องบอกว่าข้อมูลยังไม่มีหรือค้นหาไม่พบตามสถานะจริง
- รายละเอียดที่ยุบได้ใช้ `aria-expanded` / `aria-controls`; modal หากมีต้องจัดการ focus และ Escape
- ไม่มี autoplay animation/video; เคารพ `prefers-reduced-motion`

โครงเริ่มต้นยังไม่สร้างตัวเลือกจอย/ค้นหาที่กดแล้วไม่ทำงาน จะเพิ่มพร้อม behavior จริงในรอบฟีเจอร์
